What is OpenTelemetry?

OpenTelemetry (OTel) is a vendor-neutral observability standard for instrumenting, generating, collecting, and exporting telemetry data. It unifies traces, metrics, and logs under a single specification — so you instrument once and ship to any backend.

Before OTel, you'd instrument separately for each backend (Jaeger for traces, Prometheus for metrics, ELK for logs). OTel replaces this with one API, one SDK, one wire protocol (OTLP) — and you choose where the data goes.

The Resource Model

A Resource is the shared foundation across all three signals. It describes the entity producing telemetry — your service, host, container, or cloud instance. Every trace, metric, and log carries the same Resource, so you can correlate across signals and filter by source.
